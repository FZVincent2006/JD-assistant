# 招聘 JD 发布助手安装说明

本分发包包含招聘表单辅助填写扩展和可选安装的 `jd-skill`。扩展支持 Chrome、Edge；扩展文件夹为 `扩展`。

## 加载扩展

1. 解压完整分发包，并在分发包根目录运行 `shasum -a 256 -c SHA256SUMS.txt`。所有条目都应显示 `OK`。
2. 打开 Chrome 的 `chrome://extensions`，或 Edge 的 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择 `扩展` 文件夹。
4. 确认扩展已启用。打开 Boss 直聘或脉脉职位发布页面，进入扩展侧栏。

## 填写 JD

1. 选择当前平台并粘贴完整职位描述。
2. 点击“解析 JD”，检查解析结果并自行修正字段。
3. 点击“填入当前页面”，检查招聘平台里的最终内容。
4. 招聘人员自行确认并手动发布。

助手负责辅助填写，不负责替招聘人员确认或提交职位。遇到字段匹配问题，可先运行“诊断当前页面”；需要反馈交互问题时，可用点击记录功能收集页面信息。

## 安装 JD Skill

有仓库源码时，在仓库根目录执行 `bash scripts/install-jd-skill.sh`。也可将分发包里的 `skills/jd-skill` 复制到 `$CODEX_HOME/skills/jd-skill`（默认 `~/.codex/skills/jd-skill`）。重启 Codex 或新开会话后使用 `$jd-skill`。

## 回退

加载新目录前可保留上一版扩展目录。若新版本无法正常工作，在浏览器扩展管理页移除新版本，再通过“加载已解压的扩展程序”重新选择此前保留的目录。不要覆盖其他用户尚未提交的源码改动。
